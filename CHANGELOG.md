# Changelog

All notable changes to Roamly AI are documented here.

## [1.0.0] — 2026-08-18

### Added

- Interactive six-screen travel companion prototype
- Responsive mobile and desktop presentation
- Destination discovery and AI planning flow
- Trip itinerary, saved places, and profile screens
- Persistent prototype preferences using local storage
- UX case study and professional repository documentation
- Community, security, and contribution guidelines
- Issue templates and automated quality checks

### Notes

Version 1.0.0 represents the portfolio-ready interactive prototype. Live AI, authentication, booking data, and backend persistence remain future work.
