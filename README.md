# Roamly AI — Travel Companion

Roamly AI is a responsive travel companion prototype for destination discovery, AI-assisted itineraries, saved places, and trip management.

## Screens

Explore · Ask Roamly AI · Destination details · My trip · Saved places · Profile

## Project details

- **Role:** UI/UX Designer
- **Focus:** AI-assisted travel planning
- **Implementation:** Semantic HTML, responsive CSS, and vanilla JavaScript
- **Features:** Connected navigation, prompt presets, saved-place actions, and a mobile-first layout

## Live prototype

[View the interactive Roamly AI prototype](https://vinay-712.github.io/roamly-ai/)

## Run locally

Open `index.html`, or run `python -m http.server 4173` and visit `http://localhost:4173`.
